# SQL Solutions

Documenting my SQL learning journey through practice problems, clear explanations, and data analysis exercises.

## Learning Roadmap

| Stage | Topics |
| --- | --- |
| Foundations | SELECT, WHERE, DISTINCT, ORDER BY, and filtering |
| Summarising data | COUNT, SUM, AVG, GROUP BY, and HAVING |
| Combining tables | INNER JOIN, LEFT JOIN, and self-joins |
| Query logic | CASE, subqueries, and common table expressions (CTEs) |
| Analytical SQL | Window functions, rankings, and running totals |
| Practical analysis | Dates, text functions, NULL values, duplicates, and business questions |

## Solution Index

This repository is just getting started. I will add a searchable table here with each problem's name, platform, topic, SQL dialect, and solution link.

## How Solutions Will Be Organised

Solutions will be grouped by platform, with a folder for each problem. Each folder will contain:

- **solution.sql** — the query I tested.
- **README.md** — the original problem link, a short summary in my own words, the SQL dialect, and an explanation of my approach.

When useful, I will also include an alternative query and notes on edge cases such as NULL values, duplicate rows, or ties.

For my own analysis exercises, I will include table definitions, sample data, and instructions for running the queries.

## Running the Queries

Platform solutions can be tested using the linked problem's SQL editor and the dialect specified in its README.

SQL syntax can differ between MySQL, PostgreSQL, SQL Server, and other databases. Each solution will identify the dialect used.

## Learning Principles

- Understand and test each query before publishing it.
- Explain why the chosen joins, filters, and aggregations are needed.
- Review edge cases and compare alternative approaches.
- Credit references that helped me develop a solution.
